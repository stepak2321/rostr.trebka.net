## Rostr 1.3.0

### Improved
- **Server hop replaces Random server.** The Random server button is now called Server hop. It opens a random server you have not been in yet, then asks whether you want to stay or hop again.
- **Play joins a random server.** The Play button now joins a random server from the server list, so it does what the old Random server button did.
- **A new tray menu.** Right-clicking the tray icon now opens a menu that Rostr draws itself instead of the plain Windows one. It shows the Rostr version, your active account and whether Roblox is running at the top, has an icon on every row, and follows your theme. Show overlay, Discord status and Skip choosing a server are switches that stay open, so you can change several in a row. Screenshot and recording sit under Capture, and Exit is red at the bottom.
- **A nicer "still running" notice.** When you close the window and Rostr keeps running in the tray, you now get a Rostr card in the corner of the screen instead of the default Windows balloon. It has Open Rostr and Exit buttons, fades out by itself and waits while your mouse is over it. Other tray messages, like a new update or a saved screenshot, use the same card.
- **Dim menu.** A new big overlay for the whole Roblox window. Press Left Ctrl + Tab while Roblox is in front and the game screen gets darker and blurred (the blur needs Windows transparency effects, otherwise it is darker only). The top left corner shows your local time and how long you have been playing. The key that closes it and a close button sit in the top right corner, a small dock with buttons sits on the left side, and you can still play underneath. It only reacts while Roblox is in front and never takes Ctrl + Tab from other apps. Change the key, or turn it off, in Settings > Overlays.
- **Friends in the dim menu.** The middle of the dim shows the friends who are playing right now, with their picture, the game they are in and a Join button. Press Join and Rostr starts Roblox in that friend's server. Drag the top of the panel to move it, press the X on it to close it, and press the Friends button in the dock on the left side to open it again. Rostr remembers if it was open or closed and where you put it, also after a restart. The list uses the account that is active in Rostr and refreshes by itself while the dim is open. The list has its own slim scroll bar.
- **Game wiki in the dim menu.** The dock on the left side has a second button, Wiki. It opens a small browser on top of the dim with the Fandom wiki of the game you are in, for example lumber-inc.fandom.com for Lumber Inc, so you can read about the game without leaving it. Rostr searches the web for the name of the game plus "wiki" (for example "Lumber Inc wiki") and opens the first Fandom result. If the search finds nothing, it tries the Fandom address that matches the game name, and as a last step it opens the Fandom search for the game. The top of the browser has Back, Reload, Wiki home and Search Fandom buttons, and below it the address of the page, which you can select or copy with the Copy button. Drag the top to move it, press X to close it. The wiki can take the keyboard, so you can type in its search box, and the dim stays on while you do. Rostr remembers where you put it. Closing and opening it again keeps the page, and it loads a new one when you are in another game.
- **Clearer overlay names.** The two overlays now have names that say what they do. The small box with ping, CPU, RAM, time and region is the **Stats overlay**, and the screen dimmer with the clock, friends and wiki is the **Dim menu**. The Settings tab is called Overlays and holds both, and the tray menu says Show stats overlay.

### Fixed
- **Skip choosing a server skips Rostr.** With the switch on, pressing Play on roblox.com no longer opens Rostr's server list. Rostr stays closed (or in the tray), starts Roblox right away and Roblox picks the server, the same as without a launcher. If the launch fails, Rostr opens so you can read why. With the switch off, Play on roblox.com opens Rostr as before. Friend and server joins already skipped the window and still do.
- **Multi Roblox no longer piles up clients.** Rejoining, pressing Play or using Server hop with the same account used to leave the old client running, and a few joins could turn 2 clients into 50. Rostr now tags every client with the account that started it and saves the tags, so they survive a restart of Rostr. Launching again with that account closes all of its old clients, including ones Rostr had lost track of. Clients of other accounts are left alone.
- **Rostr only detects Roblox in its own Windows session.** Roblox running in an RDP session, or under another Windows user, is no longer detected, closed or recorded by Rostr. This covers Multi Roblox, closing the running client, finding the client for a launch, and screenshots and recordings.

This release includes the features from [Rostr 1.2.7](https://github.com/stepak2321/rostr.trebka.net/releases/tag/v1.2.7).
