## Rostr 1.2.7

### Improved
- **Direct joins from the Roblox website.** Joining a friend or a specific server from the website now launches directly into Roblox instead of opening Rostr's server picker. Regular Play links still open the picker.

This patch includes the features from [Rostr 1.2.6](https://github.com/stepak2321/rostr.trebka.net/releases/tag/v1.2.6).
